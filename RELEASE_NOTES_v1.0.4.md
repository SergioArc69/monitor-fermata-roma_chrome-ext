# Monitor Fermata ATAC Roma — Estensione Chrome — v1.0.4

Disponibile sul [Chrome Web Store](https://chromewebstore.google.com/detail/gggjfmkiafdeembhhglhgeignejpjdnc).

## Correzioni

- **Mappa bloccata ("403 Access blocked")**: i tile server gratuiti `tile.openstreetmap.org`,
  gestiti da volontari, hanno iniziato a bloccare il traffico generato dall'estensione secondo la
  loro [policy d'uso per app di terze parti](https://wiki.openstreetmap.org/wiki/Blocked). La mappa
  ora usa il servizio tile gratuito di [Wikimedia](https://maps.wikimedia.org/), che non richiede
  registrazione né chiavi API.

## Note tecniche

- Nessuna modifica ai permessi richiesti.
- Aggiornata l'informativa sulla privacy per riflettere il nuovo servizio di tile contattato.
